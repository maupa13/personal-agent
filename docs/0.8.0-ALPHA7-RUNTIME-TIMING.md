# Personal Agent Rus 0.8.0-alpha.7 — Windows Runtime Timing + Installer Identity

## Why this slice exists

Reference Windows evidence from 10.08.2026 proved alpha.6 functional, but exposed two product defects:

- `INSTALL-OR-UPDATE.ps1` printed `0.8.0-alpha.3 installed` while alpha.6 images were actually built;
- `VERIFY.cmd` used normal `/api/chat` in Auto mode, so verification could cold-load an administrator-selected production model. One measured request took 55.3 seconds.

## Changes

- installer version is read from signed `product-manifest.json`;
- bootstrap verification uses an admin-only `/api/admin/inference/smoke` endpoint;
- smoke always targets the small configured bootstrap model and caps generation at 16 tokens;
- local Ollama native timings are captured: provider total, load, prompt evaluation, generation, token counts and tokens/second;
- ordinary chat debug metadata receives the same native timing fields when the local provider supplies them;
- lifecycle logs separate `verification_duration` from whole-command `command_elapsed`.

## Live Windows evidence still required

Run `VERIFY.cmd` on the reference Windows PC. `PERF-A7-WIN-001` is PASS only after the log contains a successful `bootstrap-inference` probe and native timing values.
