# Почему Personal Agent Rus

Personal Agent Rus строится как local-first рабочая среда, а не как selector нейросетей.

Уже реализованные отличия текущей alpha-линии:

- локальный AI runtime на компьютере пользователя;
- Web/Research с источниками;
- работа с реальными файлами и verified artifacts;
- изолированное выполнение Python/Java/PowerShell;
- серверная история диалогов и проекты;
- локальный provider/model routing, скрытый от обычного USER;
- возможность LAN/VPS deployment foundation;
- управляемые пользователи/сессии в accounts mode;
- usage/billing foundation;
- Admin Console и structured diagnostics.

Не следует обещать как готовое то, что ещё не прошло соответствующий release gate: VK ID, полноценный SaaS billing, entitlement engine, clean-machine installer, full mobile secure-context experience и 1.0 release matrix.
