# Проверка продукта и исправления 16–17.09.2026

Статусы: **PASS** — сценарий выполнен и проверен; **PARTIAL** — работает только
указанная часть или не завершена проверка окружения; **FAIL** — воспроизводимый
сбой. Доступность модели в API не означает наличие соответствующей функции в UI.

## Обнаруженные причины

- Профиль показывал квоту AI вместо `balance.balance_rub`. Деньги не потеряны:
  зачисление 10 000 ₽, пять покупок тем на 645 ₽, остаток 9 355 ₽.
- OWNER ошибочно получал LIGHT в биллинге, хотя RBAC уже предоставлял полный доступ.
- Каталог показывал сообщение «пуст» при наличии тем, а купленные темы нельзя
  было применить из профиля. Для строк отсутствовал CSS.
- VPS запускал `main.py` из `/opt/vps-egress/app`, вне основного Git checkout.
  Пересоздание Core без внешнего Compose override теряло OpenAI egress.
- `PA_SEARXNG_URL`, `PA_BROWSER_URL`, `PA_CODE_SOCKET` в VPS Compose были пустыми.
  Запрос со сценарием поиска переходил от уточнения к HTTP 502.
- Загрузчик web-страниц не распаковывал gzip/deflate. Сжатый HTML превращался в
  нечитаемые данные, фильтр мог удалить весь источник, а отчёт завершался ошибкой
  «Недостаточно проверяемых источников». Добавлена распаковка с ограничением
  размера и регрессия на настоящем HTTP-сервере с gzip/deflate-ответами.
- Гость немедленно попадал на вход, не увидев описание сервиса.

## Поведение после исправления

- Баланс счёта отдельным крупным блоком в профиле и рядом с именем в приложении.
  Денежный баланс и квоты токенов — разные показатели. OWNER/ADMIN без тарифных
  ограничений; расходы внешнего провайдера этим не отменяются.
- Гость: два коротких запроса за скользящие 24 часа, ограничение по cookie **и** IP,
  максимум 1 000 символов, только локальная модель, без файлов/инструментов/истории.
  Резервирование атомарно в одном Core; неуспешный запрос освобождает резерв.
  Не предназначено для нескольких реплик Core без распределённого ограничителя.
- LIGHT: обычный локальный чат и история, без веба, файлов, кода, задач и remote AI.
  Ограничения применяются к API, включая старые базы, и отображаются в UI.
- MEDIUM/PRO: доступные инструменты приложения. Тариф можно оплатить с баланса
  на 30 дней, без автоматического списания. Повторное нажатие не списывает деньги
  второй раз. Переход между действующими платными периодами пока не реализован.
- Новые тарифы получают 100 000 / 500 000 remote-токенов за период для MEDIUM/PRO.
  Существующие настройки администратора не перезаписываются при старте.
  Стоимость AI оценивается только при заполненных ценах провайдера; ноль не
  является подтверждением бесплатности внешнего API. Квота проверяется до вызова,
  поэтому это не строгий денежный бюджет при параллельных запросах.
- Темы можно применить из профиля; настройка сохраняется на сервере.
  За темы, включённые в тариф или доступные администратору, повторная оплата не нужна.
- Карточная оплата при ненастроенном YooKassa отключена в UI. Оплата с баланса,
  промокоды и заявки на ручное пополнение работают независимо от неё.
- Selective CONNECT egress и urllib3 находятся в основном образе. Секреты,
  SSH private keys, `.env.vps` и база не входят в Git.

## Развёртывание и сохранность

- Изменения опубликованы в `origin/master`, рабочий checkout VPS обновлён.
- Core собирается из основного репозитория; mounts с подменой `main.py`,
  `llm_egress.py`, Python-библиотек и static больше не используются.
- На VPS работают Core, Caddy, SMTP, Ollama, SearXNG, browser, code-worker.
  Проверка через публичный HTTPS: `ready=true`, web_search/browser/code — ready.
- Smart переведён на проверенную GPT-5.2. Серверный общий OpenAI ключ учитывается
  как `PLATFORM_REMOTE`; оплаченные тарифы получили 100 000 / 500 000 токенов.
- Caddy закреплён на `172.30.0.254`; только его forwarded IP доверен Core.
  При первоначальном переключении SearXNG занял `.4`, возник конфликт адресов.
  Сервис восстановлен, постоянный адрес proxy перенесён выше динамических адресов.
- Резервная копия исходников, SQLite, Compose override и описания контейнера:
  `/opt/rodnoi-agent-backup-20260916/` на VPS, доступ только root. Предыдущий
  образ сохранён как `personal-agent-core:pre-repair-20260916`.
- Предыдущие незакоммиченные правки VPS сохранены в Git stash и резервной копии.
  Секреты, `.env.vps`, база и private keys не опубликованы.
- Тесты не меняли денежный баланс владельца. Временные сессии отозваны,
  временный аккаунт проверки тарифов и тестовые файлы удалены.
- Две локальные правки навигации Admin, существовавшие до этой задачи, сохранены
  в рабочем дереве и не включены в коммиты исправления продукта.

Для восстановления исходного развёртывания сначала распаковать `source.tgz` в
отдельный каталог, использовать сохранённый образ и исходный egress override.
Не восстанавливать старую SQLite поверх новых пользовательских данных и не
удалять Docker volumes. Резервная копия содержит секреты, её нельзя публиковать.
