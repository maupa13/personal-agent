# Personal Agent Rus 0.8.0-alpha.3 — Scenario Engine

## Цель

Этот slice делает Auto полезным для людей, которые не умеют формулировать промпты. Карточка сценария и эквивалентный свободный запрос используют один Core/Router, а не отдельные мини-приложения.

## Реализовано

- Scenario Gallery: одежда, закупки, недвижимость, подарок, товар, поездка, новости.
- Entitlement-aware выдача карточек.
- Auto detection для свободного текста.
- Явный URL имеет приоритет над auto scenario detection.
- Bounded clarification: обычно 1 сгруппированный вопрос, для закупок/недвижимости максимум 2.
- После лимита вопросов агент продолжает с явными предположениями.
- Scenario state хранится server-side per user/conversation.
- В Web/Search уходит очищенный `task_text`, без внутренних служебных маркеров.
- User Web preferences: весь интернет / предпочитать российские сайты / выбранные сайты, регион, allow/exclude domains.
- Admin site profiles: domain/category/acquisition order/egress policy metadata.
- Для сценария профиль домена участвует в scoped search; `browser/static` order реально применяется при чтении известного домена.

## Честное ограничение

`egress_region=ru/global` пока является policy metadata. Multi-region worker routing не реализован и не считается PASS. Это будет отдельный VPS/SaaS gate.

PostgreSQL server foundation присутствует с alpha.2, но `PG-RUNTIME-001` остаётся NOT_IMPLEMENTED: Local canonical storage — SQLite.

Ключевые regressions:

- внутренний текст clarification не может считаться пользовательским evidence;
- internal scaffolding не уходит в search query;
- explicit URL не перехватывается generic news scenario;
- procurement не задаёт больше двух раундов вопросов;
- Admin site profile сохраняется и audit-ится;
- Scenario Gallery проходит Chromium journey.
