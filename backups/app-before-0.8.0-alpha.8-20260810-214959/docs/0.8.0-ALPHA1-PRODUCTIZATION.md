# Personal Agent Rus 0.8.0-alpha.1 — Productization Foundation

## Цель

Перевести работающий local alpha из технической оболочки в самостоятельный пользовательский продукт, не расширяя без необходимости набор capabilities.

## Реализованный vertical slice

- server-side история диалогов в SQLite;
- проекты/папки: create/rename/delete, move conversations, pin/archive и серверный поиск по истории;
- одноразовый импорт старой browser-local истории;
- OWNER/ADMIN/USER boundary для accounts mode;
- первый зарегистрированный accounts-пользователь становится OWNER;
- USER не видит Admin navigation; в personal mode Admin также убран из sidebar и доступен владельцу только через Settings/direct Admin entry;
- Admin Console принимает роль OWNER/ADMIN без обязательного break-glass token;
- resizable/collapsible sidebar, Ctrl+B/Ctrl+N/Ctrl+K;
- компактный selector режима рядом с composer;
- Help Center по клику на бренд;
- guided USER onboarding и отдельный ADMIN onboarding;
- onboarding state/version хранится на сервере;
- structured JSONL Core logging с rotation/redaction и request/correlation IDs;
- Admin Logs, safe Diagnostics snapshot и downloadable sanitized diagnostics ZIP;
- favicon + web manifest + browser product identity;
- пользовательский встроенный guide и WHY page.

## Что намеренно НЕ объявляется готовым

- второй физический LAN-device journey;
- полноценный entitlement engine и SaaS billing lifecycle;
- VK ID/password reset/terms re-acceptance;
- Windows reboot/clean-machine gates.

Статусы этих требований должны оставаться `BLOCKED_ENVIRONMENT` или `NOT_IMPLEMENTED`, а не превращаться в PASS.

### Debug / observability quality pass

- application events сохраняются как structured JSONL;
- `request_id` / `correlation_id` проходят через Core и внутренние Web/Browser/Code/inference вызовы;
- Admin Console фильтрует логи по level/event/request/correlation;
- audit feed отделён от application log;
- доступен sanitized diagnostic ZIP без workspace, паролей, session tokens и provider secrets.

## Execution contract

Текущий execution source of truth: `docs/MASTER-IMPLEMENTATION-PROMPT-v5.md` (spec 8.0). SaaS/PostgreSQL/Scenario Engine/SEO требования из v5 входят в последующие vertical slices и не объявляются реализованными в alpha.1.
