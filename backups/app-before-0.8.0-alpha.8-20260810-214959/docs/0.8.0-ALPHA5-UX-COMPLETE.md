# Родной Агент / Personal Agent 0.8.0-alpha.5 — UX Complete Pass

## Цель

`alpha.5` завершает базовый product UX перед server/VPS beta. Он не добавляет новый backend capability-класс: он делает существующие возможности понятными, локализованными, доступными и устойчивыми для обычного пользователя.

## Brand contract

Internal:

```text
product_family = Personal Agent
product = Personal Agent Rus
edition = rus
```

USER display:

```text
ru-RU -> Родной Агент
en-US -> Personal Agent
```

Internal edition name/model/provider IDs не должны появляться в обычной USER surface.

## UX state matrix

Mandatory USER runtime states:

```text
booting
starting
degraded
offline
quota
permission
error
ready
```

Каждое проблемное состояние должно объяснять, что произошло, и давать recoverable action там, где он возможен. Raw traceback/white screen/infinite spinner недопустимы.

## Localization

RU/EN покрывают минимум:

- основной shell;
- настройки;
- account/billing copy;
- USER guided tour;
- Admin shell + Admin tour;
- Help links/guides;
- runtime/error copy;
- feedback placeholder и основные accessibility labels.

Администраторские пользовательские данные (например, вручную заданное имя провайдера) не переводятся искусственно.

## Accessibility / motion

Mandatory:

- keyboard navigation основных flows;
- visible `:focus-visible`;
- sidebar separator с ARIA min/max/current и keyboard resize;
- non-color-only runtime state;
- `aria-live` для recoverable runtime status;
- `prefers-reduced-motion`;
- clean collapsed sidebar rail.

## Responsive forms

Settings/Admin form controls должны использовать доступную ширину контейнера. Особенно проверяются:

- `#webAllowedDomains`;
- `#webExcludedDomains`;
- `#codeEditor`.

## Acceptance

Основные alpha.5 IDs:

```text
BRAND-A5-*
I18N-A5-*
UX-009-*
A11Y-A5-*
UX-A5-*
ADMIN-A5-*
```

Реальный Chromium gate проверяет RU -> EN, light theme, keyboard sidebar resize, collapse, все 9 USER-tour шагов, offline+Retry, широкие формы, account localization и Admin localization/theme/model-routing surface.

## Не входит в PASS alpha.5

```text
PG-RUNTIME-001   PostgreSQL canonical server persistence
VPS-EGRESS-001   real RU/global egress routing
BILL-LIVE-001    live merchant/HTTPS webhook
physical LAN/mobile secure-context gate
Windows reboot / clean-machine gate
```

Эти пункты не должны маскироваться статусом UX Complete.
