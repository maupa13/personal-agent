ADMIN GUIDE

Manage Personal Agent

Users choose simple modes. Administrators control which providers and models power those modes, together with roles, plans, execution policy, logs and diagnostics.

Providers

Add local or remote providers, keep API keys secret and test provider health before routing user traffic.

Models

Discover or download available models and verify that they can actually run before assigning them.

Routing

Assign provider/model combinations to Auto, Fast and Smart. Technical IDs remain an administrator concern.

Users and plans

Manage registration policy, roles, sessions and entitlements. UI hiding never replaces backend enforcement.

LAN and VPS

LAN access and server deployment have separate lifecycle/security gates. Do not expose internal services directly to the internet.

Logs and diagnostics

Use request/correlation IDs and sanitized diagnostic bundles. Secrets and private workspace contents are excluded by default.
