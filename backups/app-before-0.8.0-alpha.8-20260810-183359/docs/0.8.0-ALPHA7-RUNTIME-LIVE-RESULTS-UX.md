# 0.8.0-alpha.7 — Runtime Timing + Live Results UX

## Scope

Этот slice закрывает два класса дефектов, найденных на реальном Windows и в пользовательских скриншотах:

- stale installer version + непрозрачный inference smoke;
- слабый list/news UX: мало подтверждённых результатов, расхождение текста и карточек, неопределённые интересы, конфликт selected/focus states, отсутствие пользовательского масштаба.

## Invariants

1. `VERIFY` проверяет bootstrap model и печатает native inference timings.
2. News/list target >= 7, если реально доступно >= 7 usable evidence.
3. Если usable evidence < 7, показывается фактическое число; padding запрещён.
4. Numbered concrete list и Result Cards строятся из одного массива usable evidence.
5. Generic news starter задаёт не больше одного interest clarification; сохранённые interests используются автоматически.
6. Scenario и quick action не выглядят выбранными одновременно. Focus не равен selected.
7. UI scale: compact / normal / large.
8. Progressive reveal учитывает `prefers-reduced-motion`; это не заявляется как настоящий SSE token streaming.

## Mandatory deterministic evidence

- `alpha7_runtime_timing_acceptance.py`
- `alpha7_live_results_acceptance.py`
