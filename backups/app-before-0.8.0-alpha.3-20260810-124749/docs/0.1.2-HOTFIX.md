# Personal Agent Rus v0.1.2

## Fixed

- Windows PowerShell lifecycle wrapper no longer uses the automatic `$Args` variable.
- `START`, `STOP`, `RESTART`, `STATUS`, and `UPDATE` pass Docker Compose arguments explicitly through `ComposeArgs`.
- `START` and `UPDATE` validate `compose.yaml` before changing runtime state.
- Existing `.env` is migrated from managed core image tags `0.1.0/0.1.1` to `0.1.2` while preserving admin token, ports, bootstrap model, and custom image overrides.
- Static release checks reject reintroduction of the legacy Compose wrapper.

## Regression reproduced

The previous wrapper could invoke only `docker compose` without a subcommand, causing Docker to print its help and `Wait-Ready` to wait for a runtime that was never started.
