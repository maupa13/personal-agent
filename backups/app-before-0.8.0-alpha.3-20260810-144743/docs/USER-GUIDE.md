# Руководство пользователя — Personal Agent Rus

Версия: 0.8.0-alpha.3

## Первый вход

После открытия Personal Agent Rus запускает короткое интерактивное обучение. Его можно пропустить и в любой момент запустить снова, нажав логотип **Personal Agent** → **Пройти обучение заново**.

## Чаты и проекты

`Ctrl+N` создаёт новый чат. `Ctrl+K` переводит фокус в поиск. `Ctrl+B` сворачивает или раскрывает левую панель. Ширину панели можно изменить мышью; настройка сохраняется локально для этого браузера.

История диалогов хранится в Personal Agent, а не только в browser localStorage. Проекты помогают группировать связанные диалоги.

## Режим ответа

Около поля ввода находится компактный selector режима. `Авто` — рекомендуемый режим по умолчанию. Технические названия моделей пользователю не показываются.

## С чего начать: сценарии

На пустом экране Personal Agent показывает понятные сценарии: подобрать одежду, найти закупки, недвижимость, подарок, товар, поездку или свежие новости. Карточка только помогает начать: тот же сценарий распознаётся и обычным текстом в режиме `Авто`.

Если для точного результата не хватает важных параметров, Personal Agent задаёт один сгруппированный вопрос. Для сложных закупок/недвижимости допускается максимум два раунда; затем работа продолжается с явно указанными предположениями.

В **Настройки → Веб и сайты** можно выбрать весь интернет, предпочтение российских сайтов или только выбранные домены, а также регион и исключения.

## Веб и источники

Если запрос требует свежих данных, Personal Agent может выполнить Web/Research flow и показать источники отдельно от основного ответа. Источник не считается доказательством сам по себе: итоговый ответ должен содержать синтез результата.

## Файлы и результаты

Файлы можно прикреплять через кнопку `+`. Созданные результаты сохраняются как artifacts/workspace-файлы и могут быть скачаны. Текущий чат можно выгрузить в Markdown.

## Где помощь

Нажмите логотип Personal Agent в левом верхнем углу. Там доступны обучение, описание возможностей, пользовательское руководство и страница «Почему Personal Agent Rus».

## Если что-то не работает

Не удаляйте Docker volumes вручную. Для локальной установки используйте `VERIFY.cmd`, а при проблемах — штатный `REPAIR`/`RUN-FIRST.cmd`. Persistent log находится в каталоге `logs` установленного Personal Agent.
