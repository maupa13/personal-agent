Как пользоваться Personal Agent

Вам не нужно выбирать нейросеть или разбираться в Docker. Опишите задачу — Personal Agent использует доступные возможности и покажет результат.

1. Обычный чат

Создайте новый чат и напишите вопрос. Режим Авто подходит для большинства запросов.

2. С чего начать

На пустом экране доступны сценарии для одежды, закупок, недвижимости, подарков, товаров, поездок и новостей. Можно нажать карточку или написать ту же задачу своими словами — режим Авто использует тот же сценарный движок.

Если не хватает важных параметров, Personal Agent задаст один сгруппированный вопрос; для сложных закупок и недвижимости — не более двух раундов. После этого продолжит с понятными предположениями.

3. Свежая информация

Для новостей, сайтов и актуальных данных включите «Веб» через кнопку + или просто укажите ссылку/попросите найти свежую информацию. В «Настройки → Веб и сайты» можно выбрать область поиска, регион и предпочитаемые/исключённые сайты. Ответ должен содержать вывод и проверяемые источники.

4. Файлы

Через кнопку + загрузите TXT, MD, JSON, CSV, PDF, DOCX, XLSX или PPTX. Созданные результаты сохраняются в вашем workspace и доступны для скачивания.

5. Код

Python, Java 21 и PowerShell выполняются в отдельном sandbox без доступа к Docker socket и секретам Personal Agent.

6. Проекты и история

Диалоги хранятся сервером в локальной базе, переживают refresh и restart. Проекты помогают группировать связанные чаты.

7. Приватность

В локальном режиме основная обработка выполняется на вашем компьютере. Если в будущем задача потребует remote AI, переход должен соответствовать активной privacy-policy.

8. Помощь

Нажмите логотип Personal Agent в левом верхнем углу, чтобы повторить интерактивное обучение.
