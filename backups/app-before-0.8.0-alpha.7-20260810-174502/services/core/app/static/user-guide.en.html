How to use Personal Agent

You do not need to choose a neural network or understand Docker. Describe the result you need — Personal Agent uses the available capabilities and returns a verified result.

1. Chat

Create a chat and describe the task. Auto is the right choice for most requests.

2. Where to start

The empty screen offers scenarios for clothes, procurements, real estate, gifts, products, travel and news. You can click a card or describe the same goal in your own words.

3. Fresh information

For current information, links and news, enable Web or just ask to find fresh information. Search scope, region and preferred/excluded sites are available in Settings → Web & sites.

4. Files and artifacts

Upload TXT, MD, JSON, CSV, PDF, DOCX, XLSX or PPTX. Created results are stored in your isolated workspace and can be downloaded.

5. Code

Python, Java 21 and PowerShell run in an isolated sandbox without Docker socket or platform secrets.

6. Projects and history

Chats are stored by the server, survive refresh/restart and can be grouped into projects.

7. Privacy and execution

Choose Auto, Local only, Prefer local, Remote allowed or Remote only. Local-only is enforced by the backend, not just by the interface.

8. Help and tour

Click the Personal Agent logo to replay the guided tour.

9. Theme and language

Dark, light and system themes are available together with independent interface and response language settings.

10. Style, sharing and feedback

Response style can be changed near the composer. Sharing creates an expiring read-only snapshot; feedback can be sent without leaving the product.

11. Local installation

Open “Set up local AI” in Help for the Windows first-run path.
