Родной Агент на своём компьютере

Модели могут работать на вашем ПК, а Родной Агент сам управляет runtime. Обычному пользователю не нужно разбираться в Docker, контейнерах или ID моделей.

1

Проверьте компьютер

Windows 11, актуальный Docker Desktop и достаточно свободного места. Для локальных моделей GPU NVIDIA желателен, но конкретные требования зависят от выбранной модели.

2

Распакуйте релиз

Распакуйте ZIP Родной Агент в отдельную папку. Ваши постоянные данные потом будут жить в канонической папке установки, а не в папке распаковки.

3

Запустите установку

Откройте RUN-FIRST.cmd. Скрипт проверит Docker, подготовит сервисы, небольшую bootstrap-модель и сохранит постоянный лог. Данные существующей установки не удаляются.

4

Дождитесь «Готово»

После проверки откроется http://127.0.0.1:3100/. Если отдельная capability временно недоступна, приложение должно показать понятный degraded-статус, а не белый экран.

5

Выберите настоящую локальную модель

Владелец открывает Администрирование → Модели / Маршрутизация, видит обнаруженные модели и назначает их режимам «Авто», «Быстро» и «Умно». Bootstrap-модель нужна только для первого smoke.

6

Проверьте систему

Запустите VERIFY.cmd. Проверка должна подтвердить Core, inference и основные границы безопасности. Для строгой проверки используйте acceptance-команды релиза.

⌂

Только локально

Запросы обрабатываются локальной моделью. Если подходящей модели нет, Родной Агент не должен молча отправлять данные наружу.

⇄

Гибридно

Локальная обработка предпочтительна, а разрешённый remote provider используется только согласно выбранной политике приватности и тарифу.

☁

VPS / Web

Для серверной тестовой версии администратор подключает отдельный remote provider. API-ключ хранится на сервере и никогда не должен попадать в браузер пользователя.

Локальная сеть

Когда локальный запуск стабилен, администратор может включить LAN-доступ. На телефоне или ноутбуке открывается тот же Родной Агент; для полноценного multi-user режима используйте аккаунты и изоляцию пользователей.
