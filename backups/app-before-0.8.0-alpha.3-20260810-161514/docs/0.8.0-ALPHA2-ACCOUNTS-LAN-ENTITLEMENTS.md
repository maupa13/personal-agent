# Personal Agent Rus 0.8.0-alpha.2 — Accounts / LAN / Entitlements / PostgreSQL Foundation

## Scope

Этот vertical slice продолжает productization `0.8.0-alpha.1` и закрывает коммерческий/многопользовательский foundation, не объявляя PostgreSQL runtime готовым раньше доказательства.

### Реализовано

- backend-authoritative Entitlement Engine;
- тарифные capability/mode gates;
- Argon2id для новых паролей и миграция PBKDF2 при успешном login;
- remember-me, login throttling, session inventory/revocation;
- Admin registration policy и role/session controls;
- LAN product state, public URL и QR;
- PostgreSQL server compose/schema/driver foundation.

### Не заявлено как готовое

`PG-RUNTIME-001`: Core ещё не использует PostgreSQL как canonical persistence. До PASS нужны repository adapter, migration from SQLite, transaction/integration tests, restart, backup/restore и rollback evidence.

### Data policy

- Local/offline: SQLite остаётся канонической БД.
- Server/SaaS: PostgreSQL становится mandatory до public multi-user beta.
- Бизнес-логика не должна форкаться по БД.
