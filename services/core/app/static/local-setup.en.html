LOCAL SETUP

Set up Personal Agent on Windows

The normal user flow does not require learning Docker internals. The first-run package checks the computer, starts the runtime and verifies the product.

1

Check prerequisites

Windows 11 and Docker Desktop/WSL2 are the current reference target. A supported NVIDIA GPU is recommended for local models.

2

Extract the release

Extract the ZIP into a separate package directory. Persistent data is installed into the canonical Personal Agent directory.

3

Run RUN-FIRST.cmd

The launcher checks signed files, Docker/Compose and existing configuration, then performs an in-place install/update without deleting named volumes.

4

Open the browser

After a successful start open http://127.0.0.1:3100/.

5

Configure AI as an administrator

Open Administration в†’ Providers / Models / Routing. Users continue to see simple modes instead of technical model IDs.

6

Verify

Run VERIFY.cmd. Strict capability and release checks remain separate.
