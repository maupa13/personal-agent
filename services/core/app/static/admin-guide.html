ADMIN GUIDE

Управление Родной Агент

Пользователь выбирает понятный режим. Администратор управляет тем, какие провайдеры и модели реально стоят за режимами, тарифами и политиками исполнения.

1

Доступ

В accounts-режиме используйте аккаунт OWNER/ADMIN. В personal-режиме локальный владелец этого ПК может открыть Admin Console напрямую. Break-glass token — только аварийный путь.

2

Провайдеры

Добавьте локальный Ollama/OpenAI-compatible endpoint или remote provider. Для тестового VPS можно использовать OpenAI API через тип «OpenAI API · Responses». API key хранится только на сервере.

3

Модели

Проверьте provider health, обновите inventory, при локальном Ollama загрузите нужную модель. Технические model ID видит только администратор.

4

Маршрутизация

Назначьте конкретную provider/model пару режимам «Авто», «Быстро» и «Умно». Изменение сохраняется и должно переживать restart.

5

Тарифы и remote

Настройте entitlements, remote quotas и платёжный adapter. Локальный inference учитывается отдельно от platform-funded remote API.

6

Наблюдаемость

Используйте Logs/Audit и correlation ID. При сложной ошибке скачайте Diagnostics ZIP: секреты и private workspace по умолчанию в него не входят.
